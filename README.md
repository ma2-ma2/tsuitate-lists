# tsuitate-lists

iOS の広告ブロッカー「ツイタテ」が読み込む、独自の追加リストです。

- `tsuitate-list.txt`：AdGuard DNS filter に入っていない、日本でよく見る広告の配信元（AdGuard 形式）

アプリはリストを更新するたびに、このファイルを読みます。読めないときは、アプリに入っている版を使います。

## 足すときの決まり
- AdGuard DNS filter に入っていないことを確かめる
- 広告や計測だけに使われているドメインに限る（記事や画像も配信するドメインは入れない）
- 確かめた日付をコメント（`!`）で書く
